# WOOWANGTHON_TEAM_44_FE

2026 AI 우왕톤 44팀(그라파이트) 「당직메이트」의 당직자 화면입니다. 시나리오 엔진과 AI 파이프라인, 검증 결과는 `WOOWANGTHON_TEAM_44_BE` 저장소의 README에 있습니다.

배포 주소는 https://woowangthon-44-fe.vercel.app 입니다. AI를 부르는 요청에는 시연 코드가 필요하며, 코드는 최종 제출 폼의 테스트 계정 칸에 적어 두었습니다.

## 화면에서 볼 것

기본 시나리오는 2026년 7월 9일 새벽 청주입니다. 그날 보도로 확인한 신호와 한강홍수통제소 실측 수위로 재구성한 신호 26건이 시각대로 들어옵니다.

- 왼쪽 「들어온 신호」에는 전화 메모, 기관 통보문, 재난문자, 112·119 공조, 수위·특보 알림이 들어온 순서대로 쌓입니다. 신호마다 「보도 기반」, 「실측」, 「가상 추가」 같은 출처 표시가 붙고, AI가 읽고 있는 신호는 원문을 먼저 보여 줍니다. 「전화 메모 직접 입력」으로 넣은 메모도 같은 AI 단계를 거칩니다.
- 가운데 위 「상황판」에는 청주 지도와 수위 그래프가 있습니다. 신호가 들어온 장소에 점이 찍히고, 같은 사건으로 묶인 신호는 같은 색으로 이어집니다. 그래프는 흥덕교·장성2교 실측 수위와 관측소 기준 수위(관심, 주의, 경계, 심각) 위에 권고가 오른 시각과 당직자가 결정한 시각을 표시합니다.
- 가운데 아래 「사건」에는 AI가 묶은 사건, 규칙표가 정한 권고 등급과 당직자 결정, 시설 통제 기준 판정, 매뉴얼 원문 인용이 보입니다.
- 오른쪽 위 「AI 동료」는 무엇을 묶었고 왜 묶었는지, 어떤 조항에 해당하는지, 초안을 써 두었는지를 동료가 건네는 말처럼 보여 주고, 당직자의 결정은 오른쪽 말풍선으로 남습니다. 오른쪽 아래 「결정」에서 보고, 통제 검토 요청, 보류 중 하나를 사유와 함께 고르고, AI 초안의 수신처와 전화 스크립트, 문자를 고쳐 씁니다.
- 위쪽 「없을 때 보기」는 같은 신호가 다섯 창구로 따로 들어오는 모습을 보여 줍니다. 아래 「결정 로그」와 「인계 보고서 만들기」로 아침 인계 문서를 만듭니다.
- 위쪽 「AI 검증」 줄에는 이 세션에서 검증기가 한 일이 서버 세션 상태의 실제 집계로 쌓입니다.

어디서 나온 내용인지는 세 가지 표지로 구분합니다. 점선 「AI」는 Claude가 만든 내용, 실선 「규칙표」는 코드 규칙표가 정한 판정·권고 등급·재촉, 채운 「당직자」는 사람의 결정입니다. 재생 모드에서는 화면 위에 「재생 모드 · 기록 기반 합성 신호」 띠가 항상 표시되고, 「자세히」에서 재구성 방법과 출처를 볼 수 있습니다. 실제 전화나 문자 발송 기능은 없습니다.

## 구조

```
src/
  App.jsx                 화면 배치, 상태 줄, 초점 사건 선택, 없을 때 보기 전환
  useReplay.js            재생 시계와 서버 세션을 묶는 훅 (AI 처리 중 시계 정지, 처리 중인 신호)
  api.js                  BE 호출, 시연 코드 헤더, 브라우저 저장
  util.js                 시각 계산, 등급 이름, 사건 색
  components/
    SituationMap.jsx      상황판 지도 (Leaflet, 사건별 색 점과 연결선)
    LevelChart.jsx        실측 수위 그래프와 권고·결정 표시
    Colleague.jsx         AI 동료의 말 (세션 기록을 문장으로)
    Scatter.jsx           없을 때 보기 (창구별 신호)
    SignalFeed.jsx        신호 피드, 실시간 연동 패널, 전화 메모 입력
    IncidentBoard.jsx     첫 방문 안내, 사건 카드, 기준 판정, 인용
    DecisionPanel.jsx     결정, 사유, 수신처, 초안
    DecisionLog.jsx       결정 로그
    VerifyBar.jsx         AI 검증 집계
    Src.jsx               출처 표지 (AI, 규칙표, 당직자)
    HandoverModal.jsx     인계 보고서 미리보기, 복사, 내려받기, 인쇄
    LivePanel.jsx         공공 API 참고 조회
test/util.test.js         계산 함수 테스트, 공개 코드에 시연 코드·키 문자열이 없는지 확인
```

## 실행

```bash
npm install
# BE 저장소에서 npm run dev (3001번 포트) 를 먼저 띄운 뒤
npm run dev              # http://localhost:5173, /api는 3001로 프록시
npm test                 # 테스트 후 빌드 확인
```

배포할 때는 `VITE_API_BASE`에 BE 배포 주소를 넣습니다. 진행 상황은 브라우저에 저장되어 새로고침해도 이어지고, 「처음부터」로 지울 수 있습니다.
