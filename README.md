# WOOWANGTHON_TEAM_44_FE

2026 AI 우왕톤 44팀(그라파이트) 「당직메이트」의 당직자 화면입니다. 시나리오 엔진과 AI 파이프라인은 `WOOWANGTHON_TEAM_44_BE` 저장소에 있습니다.

화면은 하나입니다. 왼쪽에는 전화 메모, 기관 통보문, 재난문자, 112·119 공조, 시스템 알림이 들어온 순서대로 쌓이고, 가운데에는 AI가 묶은 사건과 시설 통제 기준 판정, 매뉴얼 원문 인용, 권고 등급이 보입니다. 오른쪽에서 당직자가 보고, 통제 검토 요청, 보류 중 하나를 사유와 함께 고르면 아래 결정 로그에 시각과 함께 남고, 「인계 보고서 만들기」로 아침 인계 문서를 만듭니다. AI가 한 일은 점선 테두리로, 당직자의 결정은 채운 칸으로 구분해 보여 줍니다.

재생 모드에서는 화면 위에 「재생 모드 · 합성 신호」 띠가 항상 표시됩니다. AI가 신호를 읽는 동안에는 시나리오 시계를 멈추고 무엇을 처리 중인지 보여 주며, 「다음 신호로」는 신호가 없는 시간만 건너뜁니다. 「전화 메모 직접 입력」으로 넣은 메모도 시나리오 신호와 같은 AI 단계를 거칩니다. 실제 전화나 문자 발송 기능은 없습니다.

## 실행

```bash
npm install
# BE 저장소에서 npm run dev (3001번 포트) 를 먼저 띄운 뒤
npm run dev              # http://localhost:5173, /api는 3001로 프록시
```

배포할 때는 `VITE_API_BASE`에 BE 배포 주소를 넣습니다. 진행 상황은 브라우저에 저장되어 새로고침해도 이어지고, 「처음부터」로 지울 수 있습니다.

## 사용한 외부 기술

React, Vite, marked(인계 보고서 미리보기), IBM Plex Sans KR 글꼴을 사용했습니다.
