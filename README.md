# WOOWANGTHON_TEAM_44_FE

2026 AI 우왕톤 44팀(그라파이트) 「당직메이트」의 당직자 화면입니다. 시나리오 엔진과 AI 파이프라인, 검증 결과는 `WOOWANGTHON_TEAM_44_BE` 저장소의 README에 있습니다.

배포 주소는 https://woowangthon-44-fe.vercel.app 입니다. 로그인 화면에서 「체험 계정으로 시작」을 누르면 접속 코드 없이 들어갑니다. 기관 접속 코드는 최종 제출 폼의 테스트 계정 칸에 적어 두었습니다.

## 화면

기본은 실제 당직실에서 켜 두고 쓰는 근무 화면입니다. 지난 호우 기록을 재생하는 장치는 「연습하기」로 옮겼습니다. 처음 로그인하면 연습을 권하고, 메뉴에서 언제든 다시 열 수 있습니다.

뼈대는 하나입니다. 위에는 소속, 시각, 화면 전환, 인계 보고서가 있고, 왼쪽 사건 줄은 「결정할 사건」, 「지켜보는 사건」(관찰, 보류 중), 「처리한 사건」으로 나뉩니다. 가운데와 오른쪽은 지금 상황에 맞춰 바뀝니다.

- **평시:** 결정할 사건이 없다는 한 줄과 「받은 전화 적기」가 있고, 오른쪽에 충청북도의 지금 하천 수위, 기상특보, 긴급재난문자가 실제 공공 API 값으로 보입니다.
- **신호가 들어올 때:** 원문이 위에 먼저 뜨고, AI가 읽고 나면 어느 사건에 묶었는지(새 사건, 기존 사건, 시 전체 안내) 한 줄로 알린 뒤 사건 줄로 들어갑니다.
- **결정할 사건이 하나일 때:** 가운데에 사건 하나, 권고(규칙표), 근거 세 줄, 당직자가 할 일을 적은 매뉴얼 조항, 결정 버튼 셋(통제 검토 요청, 보고, 보류)만 둡니다. 버튼을 고르면 사유와 전달 사항, 연락한 곳이 열립니다. 전달 사항은 AI가 「무슨 일, 어디, 언제, 누가 알려 옴」 두세 줄과 요청 한 줄로 정리한 메모이고(수치·시각은 근거와 대조), 복사하거나 고칠 수 있습니다. 연락은 당직자가 전화나 메신저로 직접 하고, 기관마다 「전달함」 또는 「회신 대기」와 한 줄 메모(받은 사람, 들은 말)를 남깁니다. 회신 대기인 곳은 사건 줄과 근무 기록의 「인계할 것」에 남고, 「회신 받음」으로 닫습니다. 오른쪽 근거 서랍은 권고 근거에 맞는 탭을 먼저 엽니다. 수위가 근거면 실측 수위 그래프, 지하차도나 하부도로면 지도, 그 밖에는 신호 원문입니다.
- **보류한 사건이 다시 올라올 때:** 규칙표의 재촉과 함께 「이 사건의 흐름」(신호, 권고, 보류, 재촉을 시각 순으로)이 펼쳐집니다.
- **결정할 사건이 셋 이상일 때:** 지도를 크게 펼친 상황판으로 바뀌고, 아래에 결정할 사건이 나란히 놓입니다. 하나를 고르면 결정 화면으로 갑니다.
- **근무가 끝났을 때:** 밤 전체 흐름, 인계할 것(결정 전 사건, 회신 대기), 인계 보고서 만들기, 검증 기록(이 세션에서 검증기가 실제로 한 일)을 한 화면에 둡니다.

화면을 바꾸는 규칙은 AI가 아니라 코드(`util.js`의 `chooseView`)가 정하고, 위쪽 「지금 할 일, 상황판, 근무 기록」으로 원하는 화면을 고정할 수 있습니다. 내용의 출처는 세 가지 표지로 구분합니다. 점선 「AI」는 Claude가 만든 내용, 실선 「규칙표」는 코드 규칙표가 정한 판정·권고·재촉, 채운 「당직자」는 사람의 결정입니다.

## 연습 모드

연습은 게임의 튜토리얼처럼 진행합니다. 재생, 배속, 시나리오 선택 같은 조작은 없습니다. 신호가 시각대로 흐르다가(빈 시간은 빠르게 넘기고, 신호마다 AI 처리는 실제로 거칩니다) 연습할 순간에 멈추고, 화면 위 한 줄 안내에 따라 실제 기능을 직접 씁니다. 2026년 7월 9일 청주 연습은 일곱 단계입니다.

1. 미평천의 권고가 통제 검토 요청으로 오름
2. 무심천 홍수주의보, 하상도로 침수 신고는 아직 없음(보류해 보기)
3. 가덕면 요양원 축대 붕괴, 12명 대피(보고, 전달 사항을 보고 연락 결과 남기기)
4. 보류한 무심천에 수위가 주의 수위를 넘어 재촉(흐름을 보고 다시 결정)
5. 받은 전화 직접 적기(화면이 들려주는 내용을 입력, 「직접 입력」으로 표시)
6. 문암철교 하부도로 침수 경찰 공조
7. 결정할 사건이 여러 곳에서 쌓여 상황판으로 전환

멈출 순간은 사건 번호가 아니라 장소와 권고로 찾기 때문에(`practice.js`) 재생마다 AI가 묶은 결과가 조금 달라도 같은 순간에 멈춥니다. 끝나면 인계 보고서, 「당직메이트 없이 받았다면」(같은 신호를 다섯 창구로 흩어 놓은 화면), 「실제 근무로 돌아가기」로 이어집니다. 연습 화면 위에는 「연습, 2026.07.09 청주 기록 재구성, 실제 발송 없음」 표지가 항상 있고, 누르면 재구성 방법과 출처가 보입니다. 신호마다 보도 기반, 실측, 가상 추가, 직접 입력을 표시합니다.

## 구조

```
src/
  App.jsx                 로그인 여부, 모드(실제 근무·연습·저장 기록), 화면 자동 전환
  useSession.js           세션 훅: 실제 근무(지금 시각), 연습(기록 재생, AI 처리 중 시계 정지), 저장 기록(읽기 전용)
  practice.js             연습 대본과 진행기(멈출 순간, 안내 문장, 다음 단계)
  api.js                  BE 호출, 접속 정보 한 번 저장, 상한 도달 처리
  util.js                 시각 계산, 사건 줄 분류, 화면 전환 규칙, 근거 서랍 첫 탭
  components/
    Login.jsx             기관 접속 코드, 체험 계정, 저장된 연습 기록
    Welcome.jsx           처음 온 사람에게 연습 권하기, 연습 목록
    Header.jsx            소속, 연습 표지, 화면 전환, 시각, 메뉴
    Queue.jsx             사건 줄
    Arrival.jsx           신호 도착과 묶은 결과 한 줄
    Standby.jsx           평시 화면
    MemoBox.jsx           받은 전화 적기
    Focus.jsx             결정 화면
    DecisionForm.jsx      사유, 전달 사항, 연락한 곳과 결과, 기록
    Flow.jsx              이 사건의 흐름
    Drawer.jsx            근거 서랍(수위, 지도, 신호, 기준과 조항, 전체 신호, 충북 실시간)
    LevelChart.jsx        실측 수위 그래프와 결정 시각
    SituationMap.jsx      지도(Leaflet, 위험도 색 점)
    LiveData.jsx          충북 실시간 수위·특보·재난문자
    Overview.jsx          상황판
    Night.jsx             근무 기록과 검증 기록
    Scatter.jsx           당직메이트 없이 받았다면
    Coach.jsx             연습 시작·안내·마침
    HandoverModal.jsx     인계 보고서 미리보기, 복사, 내려받기, 인쇄
    Src.jsx               출처 표지
public/records/           저장된 연습 기록(11/9 실제 재생을 끝까지 마친 세션)
test/util.test.js         화면 계산 함수 테스트, 공개 코드에 키나 비밀값 이름이 없는지 확인
```

## 실행

```bash
npm install
# BE 저장소에서 npm run dev (3001번 포트) 를 먼저 띄운 뒤
npm run dev              # http://localhost:5173, /api는 3001로 프록시
npm test                 # 테스트 후 빌드 확인
```

배포할 때는 `VITE_API_BASE`에 BE 배포 주소를 넣습니다. 접속 정보와 진행 상황은 브라우저에 저장되어 새로고침해도 이어집니다.
