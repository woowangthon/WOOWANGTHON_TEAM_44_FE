## 흐름
업무 지시 → **1 검수**(왼쪽 원자료, 오른쪽 AI 신입의 결과물. 틀린 문장을 눌러 표시하고 사유를 고름) → **2 판정**(승인·반려) → **3 신입의 답**(맞게 짚은 곳은 고쳐 오고, 멀쩡한 곳을 짚었으면 원자료 인용으로 되묻고, 놓친 곳은 최종본에 빨갛게 남음) → **4 성적표**(찾음·놓침·멀쩡한데 짚음, 판정, 같은 과제를 처음 푼 사람 가운데 찾은 비율, 과제를 만들고 검증한 방법).

첫 화면의 「실제 검사가 보는 것, 여기서 하는 것」에는 채용·직무 평가의 AI 역량 검사가 보는 것과 이 연습을 출처와 함께 대응시켰습니다. 실제 검사는 프롬프트 설계와 보완도 보지만, 여기서는 결과 검증만 떼어 연습합니다.

## 실행
```
npm ci
npm test        # 단위 테스트와 빌드
npm run dev     # http://localhost:5173 (/api는 BE의 localhost:3001로 프록시. 배포 때는 VITE_API_BASE에 BE 주소)
```
