# WOOWANGTHON_TEAM_44_FE

2026 AI 우왕톤 44팀(그라파이트) 「당직메이트」의 당직자 화면입니다. 시나리오 엔진과 AI 파이프라인, 검증 결과는 `WOOWANGTHON_TEAM_44_BE` 저장소의 README에 있습니다.

배포 주소는 https://woowangthon-44-fe.vercel.app 입니다. AI를 부르는 요청에는 시연 코드가 필요하며, 코드는 최종 제출 폼의 테스트 계정 칸에 적어 두었습니다.

## 화면에서 볼 것

화면은 하나입니다. 처음 열면 가운데 사건 칸에 무엇을 하는 서비스인지, 무엇을 누르면 되는지, 누가 무엇을 맡는지가 안내되고, 첫 사건이 생기면 안내는 사라집니다.

- 왼쪽 「들어온 신호」에는 전화 메모, 기관 통보문, 재난문자, 112·119 공조, 시스템 알림이 들어온 순서대로 쌓입니다. AI가 읽고 있는 신호는 원문을 먼저 보여 주고, 처리가 끝나면 요약과 묶인 사건이 붙습니다.
- 가운데 「사건」에는 AI가 묶은 사건, 시설 통제 기준 판정, 권고 등급, 매뉴얼 원문 인용이 보입니다.
- 오른쪽 「결정」에서 당직자가 보고, 통제 검토 요청, 보류 중 하나를 사유와 함께 고릅니다. 수신처와 전화 스크립트, 문자는 AI 초안을 고쳐 쓰고, 초안의 수치·시각이 근거 신호와 대조됐는지 함께 표시됩니다.
- 아래 「결정 로그」에는 사건 생성, 권고 상향, 재촉, 당직자 결정이 시각순으로 남고, 「인계 보고서 만들기」로 아침 인계 문서를 만듭니다.
- 위쪽 「AI 검증」 줄에는 이 세션에서 검증기가 한 일이 서버 세션 상태의 실제 집계로 쌓입니다(AI 호출, 원문 대조를 통과한 인용과 막은 인용, 근거 구절을 확인한 사실과 버린 사실, 대조한 초안 수치·시각과 경고, 검증에 걸린 AI 답).

어디서 나온 내용인지는 세 가지 표지로 구분합니다. 점선 「AI」는 Claude가 만든 내용, 실선 「규칙표」는 코드 규칙표가 정한 판정·권고 등급·재촉, 채운 「당직자」는 사람의 결정입니다. 시스템 알림처럼 규칙으로 정리한 신호의 요약은 「자동 요약」으로 따로 표시합니다.

재생 모드에서는 화면 위에 「재생 모드 · 합성 신호」 띠가 항상 표시됩니다. AI가 신호를 읽는 동안에는 시나리오 시계를 멈추고 무엇을 처리 중인지 보여 주며, 「다음 신호로」는 신호가 없는 시간만 건너뜁니다. 권고 등급이 오르면 재생이 멈추고(「권고가 오르면 멈춤」), AI 호출이 실패하면 오류를 보여 준 뒤 「재생」으로 같은 신호를 다시 처리합니다. 「전화 메모 직접 입력」으로 넣은 메모도 시나리오 신호와 같은 AI 단계를 거칩니다. 실제 전화나 문자 발송 기능은 없습니다.

## 구조

```
src/
  App.jsx                 화면 배치, 상태 줄, 초점 사건 선택
  useReplay.js            재생 시계와 서버 세션을 묶는 훅 (AI 처리 중 시계 정지, 처리 중인 신호)
  api.js                  BE 호출, 시연 코드 헤더, 브라우저 저장
  components/
    SignalFeed.jsx        신호 피드, 실시간 연동 패널, 전화 메모 입력
    IncidentBoard.jsx     첫 방문 안내, 사건 카드, 기준 판정, 인용
    DecisionPanel.jsx     결정, 사유, 수신처, 초안
    DecisionLog.jsx       결정 로그
    VerifyBar.jsx         AI 검증 집계
    Src.jsx               출처 표지 (AI, 규칙표, 당직자)
    HandoverModal.jsx     인계 보고서 미리보기, 복사, 내려받기, 인쇄
    LivePanel.jsx         공공 API 참고 조회
test/util.test.js         계산 함수 테스트, 공개 코드에 시연 코드·키 문자열이 없는지 확인
```

## 실행

```bash
npm install
# BE 저장소에서 npm run dev (3001번 포트) 를 먼저 띄운 뒤
npm run dev              # http://localhost:5173, /api는 3001로 프록시
npm test                 # 테스트 후 빌드 확인
```

배포할 때는 `VITE_API_BASE`에 BE 배포 주소를 넣습니다. 진행 상황은 브라우저에 저장되어 새로고침해도 이어지고, 「처음부터」로 지울 수 있습니다.

## 사용한 외부 기술

React, Vite, marked(인계 보고서 미리보기), IBM Plex Sans KR 글꼴을 사용했습니다.
